Your Stremio addons,
native on LG TVs.

A fast app for LG webOS, written in C. You bring your Stremio account and your addons. It ships empty and plays only the links your addons return.

Install on your TV Download .ipk

Install

Homebrew Channel

For TVs set up with the webOS Homebrew tools. Updates arrive by themselves.

  1. Open the Homebrew Channel, then its settings, then Repositories.
  2. Add this address:
https://origin-webos.vercel.app/apps.json
  1. Find Stremio Origin in the list and install it.

Developer Mode

  1. Install Developer Mode from the LG Content Store, sign in, turn on Dev Mode and Key Server.
  2. On a computer, install Device Manager for webOS and add the TV.
  3. Download the latest .ipk from Releases and install it.

Developer Mode runs out after a while: press Extend in its app to keep it on.

What it does

  • Home, Discover, Library and Search from your Stremio account
  • Seek previews on the seek bar, for debrid and direct links
  • The best stream in one press, and a sources tray per addon
  • Styled subtitles with fonts, size, colour, position and sync
  • Subtitles and audio remembered for each show
  • Chapters, skip intro and recap, next-episode card
  • Live TV and sports from your addons
  • Film collections, and the next film after the credits
  • Trakt: link with a code, scrobbling and watched marks
  • Dolby Vision, DTS sound converted on the TV
  • Torrents, with an optional USB drive
  • 28 languages, Arabic included

Something wrong?

On the TV open Settings › About › Share logs. You get a short code. Then open an issue on GitHub with the code and what happened.
